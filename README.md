One sentence that explains the modern internet to a traveler just out of 1800, using only words that already existed in their time: "From one chair you may read every book ever printed, and a letter whispered into a copper wire reaches a friend in Canton before the ink dries." The program writes that single sentence to `/output/entry.txt` — one sentence, 143 characters. The chair is the machine, unnamed; the library of every book ever printed is the web's knowledge; the whispered letter is the network; and the ink that has not yet dried is the shock — in 1800 a letter from London to Canton took half a year by ship, and here it arrives before the ink dries.

## Run it

```sh
python3 main.py
```

It creates the output directory if needed, writes `/output/entry.txt` as UTF-8 (one sentence, 143 characters, no trailing newline), and reads the file back to confirm it matches the sentence exactly.
